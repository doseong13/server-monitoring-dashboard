# Server Monitoring Dashboard

여러 VM의 CPU, 메모리, 디스크 사용량을 한눈에 확인하는 서버 모니터링 대시보드입니다.

## 문제 정의

여러 서버의 상태를 확인하려면 서버마다 SSH로 접속해야 합니다.
이 프로젝트는 각 서버가 주기적으로 상태를 전송하도록 하고,
중앙 대시보드에서 서버 상태와 경고를 확인할 수 있도록 합니다.

## 주요 기능

- 서버별 CPU, 메모리, 디스크 사용량 수집
- 서버별 최신 상태 조회
- 임계치 초과 시 경고 기록
- 오래된 지표의 시간 단위 집계
- 서버 미응답 감지

## 기술 스택

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Python Agent
- Docker
